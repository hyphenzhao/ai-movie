# v3.2 进行中 — 语音转换分块、pyannote 说话人日志、3D 口型试验（2026-09-17）

## 1. "一个人像好几个人在说话"：语音转换改为分块

**原因**（三部片实测）：v2 逐段独立做语音转换，回退到内置音色的段 output_test 33/127、test_1 11/54、
test_2 17/77，其中约六成是 <0.7 秒的短句（按设计不转换：0.6 秒以下转换会整句变成别的话），
其余是 1 秒左右短句转换失败。回退段夹在克隆段中间，音色来回跳。

**做法**（`tts.run_vc_conversion`）：连续同说话人、同参考音的短段拼成 ≥1.5 秒的块（行间插 0.45 秒静音，
块长上限 12 秒），整体转换后在插入静音处切回（期望位置 ±250 ms 内能量最低的 100 ms 窗），
每段去掉继承的静音，交给下游按 v1 时长钉齐。混采样率的块退回逐段。

| | test_1 | test_2 | output_test |
|---|---:|---:|---:|
| 回退内置音色（改前 → 改后） | 11 → **0** | 17 → **0** | 33 → **1** |
| 时间轴漂移 | 0 ms | 0 ms | 0 ms |

verify_dub：内容识别中位重合 1.00、音高 0/18 出性别区间；QC 的 `vc_kept_builtin` 从三部片全部消失，FAIL 比例不变。

## 2. 说话人日志：pyannote 簇 + 逐段音高性别

**为什么能用 pyannote**：官方 `speaker-diarization-3.1` / `community-1` 都是 gated，本账号不在授权名单
（每个文件 403）。但它们的组件不受限：`segmentation-3.0`（已用于重叠检测）+ WeSpeaker ResNet34
（权重 26 MB，直连 0.4 MB/s 爬不动，经 VPS 中转放在 `models/wespeaker-voxceleb-resnet34-LM/`）。
`ai_movie/diar_worker.py` 在 osd_venv 里按 3.1 的超参数组装；pyannote 4 会强制加载 gated 的 PLDA
（只给 VBx 聚类用），对 AHC 无用，stub 掉即可。三部片 22–77 秒出结果（CPU）。

**为什么不能只用 pyannote**：它决定"谁在说"很强（test_1 第一次找到了第二个说话人，那个簇疑问句占 39%，
就是主持人），但簇级性别会把画外男主持的短问句并进女演员的簇——output_test 的 107 Hz 男声整个消失，
验收 A4/A5 回退。所以性别仍按**单元音高**判断：单元 ≥0.6 秒且有音高证据时用自己的性别，
同性别零散段并成一个说话人，与已有同性别簇 ECAPA 距离 <0.55 才并入。另外 ECAPA 质心距离 <0.55 的簇合并
（test_2 有一对 0.32 的过度切分，真实说话人对都 ≥0.65）。重叠段取覆盖最长的簇——即"只配主说话人"。

| | test_1 | test_2 | output_test |
|---|---|---|---|
| 说话人（改前） | 1 女 | 1 女 + 1 男 | 1 女 + 1 男 |
| 说话人（改后） | **2 女 + 1 男（2 段）** | 2 女 + **2 男** | 2 女 + 1 男 |
| A2a/A3/A4/A5 | ✗✗✗ → **全过** | 全过 → 全过 | 全过 → 全过 |

未解：无音高证据的段（男主持吼叫、气声）仍跟簇走；output_test 旧版 12 个男声段现在找回 6 个。
`DIARIZE_BACKEND` 默认 `pyannote`，`--diarize-backend ecapa` 可回退。

**画面反向纠正**（`DIARIZE_FACE_FEEDBACK`）：faces 阶段记录"人脸性别置信 ≥0.8 而声学置信 <0.5"的矛盾段到
`04_face_gender_conflicts.csv` 与 state。**只记录不自动改**：faces 在 TTS 之后，改标签会留下错误音色的合成音；
应用交给 Web 编辑器 / `review_speakers.py`（它们会让 tts 起过期重跑）。

## 3. 3D/姿态鲁棒口型（LatentSync 1.6）——环境就绪中

- 代码：`vendor/LatentSync`；Python 3.10 由 uv 装在用户空间（无 sudo）；依赖改用 ROCm 版 torch 2.6。
- 权重 5.07 GB 经 VPS 中转，网络极差（0.14 MB/s），预计数小时；`tiny.pt` 已到。
- 需要改的地方：`scripts/inference.py` 硬编码 `cuda`（ROCm 下 torch 也叫 cuda，通常可直接跑）；
  1.6 需要 18 GB 显存，本机统一内存足够。
- 试验设计：只对 test_1 / test_2 被门控跳过的侧脸段做 A/B（yaw >55° 或人脸 <80 px 的 1341 帧），
  量 D3/D4/D6 和清晰度；再按帧率外推 30/60/90 分钟的耗时。
