## 存储位置

- 服务器：`//192.168.50.6/PrivateFiles`。
- 项目目录：`AI-Movie`，本次挂载后创建。
- 本机路径：`/home/ai-movie/mnt/PrivateFiles/AI-Movie`。
- 协议及挂载：现有 rclone 的 SMB 后端，通过 FUSE 提供本机文件路径；无需管理员权限。
- 用户服务：`ai-movie-smb.service`，随用户服务启动，并在故障后重试。Web 服务依赖此挂载。
- 凭据保存在用户私有配置目录的权限为 0600 的文件中，不进入仓库。rclone 的密码字段是可逆混淆，保护依赖文件和父目录权限。

| 服务器内路径 | 内容 | 本机兼容路径 |
|---|---|---|
| `AI-Movie/inputs` | 测试原片、字幕、长片分块链接 | 项目 `inputs` 软链接 |
| `AI-Movie/test_data` | 旧测试素材和结果 | 项目 `test_data` 软链接 |
| `AI-Movie/deliver` | 当前成片、样片、验收报告 | 项目 `deliver` 软链接 |
| `AI-Movie/projects` | 测试工程存档 | 项目 `projects` 软链接 |
| `AI-Movie/workspace` | 测试中间文件、A/B 结果、版本归档 | 本机 `workspace` 下逐项软链接 |
| `AI-Movie/workspace/_cache` | 补迁的测量 JSON、测试日志和字幕网页缓存 | 本机 `_cache` 下逐项软链接 |
| `AI-Movie/output_test.aimovie.json` | 根目录旧测试工程 | 原位软链接 |
| `AI-Movie/releases/<版本>` | 验收通过后的冻结交付 | 发布脚本生成 |

本机 `workspace` 和 `_cache` 目录本身保留。`_cache` 中的脚本、依赖安装包、安装日志和私有访问配置留在本机，测试结果及测试历史日志迁移并原位链接。`_web` 的实时任务注册表及 `web.log` 留在本机。代码、`tests` 测试源码、模型、Python 环境和源码压缩归档不迁移。

SMB 时间戳精度低于本机纳秒精度，原始时间已保存在迁移清单中。管线输入指纹包含修改时间，迁移后某些旧阶段可能被判为需要重算；文件内容校验和路径兼容并不保证所有旧缓存指纹原样有效。不要用全局 `--fp-adopt` 隐藏 v3.4 的真实代码变化。

## 后续发布

`scripts/run_release.sh` 和 `scripts/run_v34_regression.sh` 均在挂载可用时运行，验收成功后调用 `scripts/publish_smb.py`。旧 `workspace/_cache/v34_regression.sh` 仅转发到正式脚本。管线失败立即停止，不能继续把上轮成片复制成新版。

用户已另行授权交付 v3.4 成片供评测。`run_v34_regression.sh` 调用 Python 编排器，先生成并交付三部短片，再完成长片。`publish_evaluation.py` 将真实完成但可能有质量失败的候选放到 `AI-Movie/evaluations/v3.4/<run-id>`（短片先行包为 `<run-id>-shorts`），附入口、报告、逐片凭据与 SHA256 清单，始终明确标记 EVALUATION / NOT ACCEPTED；这不会绕过正式 releases 的质量门。每块凭据绑定源代码、状态、声音档案和实际成片；长片另绑定全部块、原片直通段及实际拼接清单。`LATEST_EVALUATION.json` 仅在服务器写入确认后更新。

发布器独立检查验收 JSON 的汇总以及每条验收门，确认覆盖请求的影片，拒绝空成片和晚于验收报告的成片。复制先进入版本临时目录，经 SHA-256 校验及挂载上传队列确认后再成为正式版本。已存在的同名版本拒绝覆盖，失败时保留临时目录用于检查。

挂载采用写缓存，缓存上限目标为 20 GiB，关闭文件后上传；未上传完成的文件不会为满足缓存目标而被丢弃。不要在上传队列未排空时关机或卸载。发布脚本会等待队列排空后才返回成功。

常用检查命令：

```bash
systemctl --user status ai-movie-smb.service
python3 scripts/publish_smb.py --check-mount
systemctl --user status ai-movie-testdata-copy.service
```

原有 `AI_MOVIE_UPLOAD` 仅控制 VPS、Drive 等公网发布，默认关闭；SMB 发布不依赖该开关。`HF_HUB_OFFLINE` 仍可由调用者显式指定，发布及长片脚本不再因旧流量限制强制离线。
