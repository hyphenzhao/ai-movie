# 演员名术语表（2026-09-17）

人名是这条流水线最主要的一类 ASR 错误：v3.0.0 把「瀬戸（せと）」听成「セット」，翻译如实
译成了"套装"。名单有两个用处——**当 Whisper 热词**让读音被认出来，**当术语表钉死**中文译名。

## 数据来自 Wikidata，不是手写

`scripts/fetch_name_glossary.py` 用 SPARQL 抓取，每条都有 Q-id 可核对：本国语标签、
假名读音（P1814）、中文标签（zh-hans/zh-cn/zh）、别名、性别（P21）、出生年（P569）。
**没有手写名单**——错误的假名读音当热词比没有热词更糟。

```bash
python scripts/fetch_name_glossary.py --country jp          # 单国
python scripts/fetch_name_glossary.py --country jp,kr,vn,th # 四国，约 20 秒
python scripts/fetch_name_glossary.py --build               # 只重建衍生文件
```

产物在 `asset/names/`（该目录按仓库惯例不入库，脚本 20 秒可复现）：
`jp/kr/vn/th.json` 原始行、`glossary_seed.json` 写法→中文、`hotwords.json` 每语言读音表。

## 为什么不能全局注入（`ai_movie/names.py` 的存在理由）

- **别名指向别人**：`あずみ→上原杏美`、`イヴ→神代弓子`、`アッコ→中村晃子`。全局钉死会把
  任何叫あずみ的人都改名。
- **读音是普通词**：「ひとみ」（瞳）、「つぐみ」（斑鸠）、「あい」（爱）——钉死会破坏正常台词。
- **热词有长度上限**：Whisper `initial_prompt` 只能放两百来 token，日文一项就有约 2000 个写法。

所以：**只钉"姓+名"齐全的规范写法**（判据是 Wikidata 假名字段带空格，说明姓名分明），
别名只当热词，且**按影片筛选**。1742 行里可安全钉死的有 756 条。

```python
from ai_movie import names as N
N.select_for_segments(asr_segments)      # 转写里真出现的名字 → 术语表条目
N.select_by_name("Sora Aoi")             # 按任意写法查（片源元数据/文件名）
N.hotword_prompt(rows)                   # → "出演者：蒼井そら、あおいそら"
```

## 还没接进流水线，以及为什么

- **术语表侧**（事后钉中文译名）：可以直接接 `glossary.build_glossary`，把
  `select_for_segments` 的结果并进去（用户 seed 优先）。只在 ASR 把名字**大致听对**时有用。
- **热词侧**（事前给读音）：这才是真正能修「瀬戸→セット」的一环，但它要求**开跑前就知道演员是谁**。
  转写还没产生，没法从转写里找。可行路径：工程里加一个"演员"字段（Web 界面填）、或从
  文件名/番号查片源元数据。这一步没做。
- 改 `ASR_INITIAL_PROMPT` 会让 asr 指纹失效、三部片全部重跑，所以默认关闭，等热词来源定了再开。

## 第二个来源：javtxt.com（补当前演员）

`scripts/fetch_javtxt_names.py`。该站演员页正好给出三语字段，正是 Wikidata 缺的那部分：

```
演员(女优): めぐり     中文名：藤浦惠   英文名：Meguri   别名：藤浦めぐ
```

只抓 `/actress/<id>`，**不碰影片页、不抓图片**，只保留姓名/别名/生日字段；请求串行、间隔 1.5 秒、
HTML 落盘缓存，重跑不再打扰站点。该站 robots.txt（2026-09-17 查）没有任何 User-agent/Disallow，
也没设置内容信号。页面结构是 `<dt>标签：</dt><dd>值</dd>`，按定义对解析（用扁平文本正则会全部取空）。

```bash
python scripts/fetch_javtxt_names.py --pages 30
```

结果：**309 位演员，135 位三语齐全**（站点索引 `/top-actresses` 只有 7 页，这就是其全部排行覆盖）。
合并后可安全钉死条目 756 → **920**，其中 javtxt 新增 95 条（波多野結衣、希志あいの、仲村みう…）。

**测试片的瀬戸環奈在 javtxt 里**（Wikidata 没有），但站上没给她中文名；参考字幕里是"濑戸环奈"。
顺带发现：现有种子术语表把 `カンナ` 钉成"坎娜"，按本名应为"环奈"——这是个可修的实际错误，
但改它会让 glossary→translate 及之后全部重跑，留待下一轮。

## 第三个库：主流演员（单独存放，默认不启用）

成人用品广告翻译会涉及有名气的普通演员，所以 `--mainstream` 另建一套
`<cc>_mainstream.json`，用 Wikidata 的"演员"职业（Q33999）且要求有中文标签：
日 8140 / 韩 4236 / 泰 1142 / 越 169，约 1.37 万人。

这套**不并入**默认库；`names.load_rows(mainstream=True)` 才会带上。原因是量级差一个数量级，
而且普通演员名与日常词汇撞车的概率更高。

抓取注意：带别名聚合的查询在 500/页时会被 WDQS 502/429 拒绝，主流库改用不含聚合的轻量查询、
300/页、页间停 3 秒、429 时退避 60 秒起，并且每页落盘，断了能接着来。

## 已知缺口

- **当前演员覆盖仍然有限**：javtxt 补上了瀬戸環奈等在做的演员，但其索引只有排行榜 7 页共 309 人；
  要覆盖任意片子仍需番号→演员表这条路。三部测试片的转写里一个名字都没出现过，所以术语表这一侧
  对它们没有直接收益。
- **越南、泰国几乎是空的**（4 和 17 条），中文译名更少。这两个市场得另找数据源。
- 韩国名单没有读音字段（P1814 是日语专用），韩语 ASR 热词只能用谚文标签本身。
