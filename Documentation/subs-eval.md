# 字幕对照评测（2026-09-15）

`scripts/eval_against_subs.py` 用片源自带的烧录字幕（上中文、下日文）作为 ground truth，
把「ASR 听错」和「翻译翻错」分开量化，任何流水线改动后都能重跑出客观分数。

## 用法

```bash
# 1. 每段一条字幕条，拼成带编号的读图版 + 空白 gt_ja.json
.venv/bin/python scripts/eval_against_subs.py output_test --make-tiles
#    → workspace/<name>/eval/tiles/t_*.png（8 段一张），把画面日文逐段填进 eval/gt_ja.json
#      （无字幕的段留空字符串）。这是唯一的人工步骤，同一片源只做一次。

# 2. 打分（参考译文 SRT 可选）
.venv/bin/python scripts/eval_against_subs.py output_test --ref-srt inputs/subs/output_test.zh.srt
#    → deliver/<name>/09_subs_eval.md（报告）、workspace/<name>/eval/subs_eval.json（明细）
```

读图裁的是 1080p 画面 y=870 起 210 px 的底部带；换片源分辨率或字幕位置时改 `BAND`。
读图版可以直接交给 Claude 读（本次 128 段 16 张图全部由 Claude 读出）。

## 口径

- 同一句字幕跨越的多个 ASR 段先合并再比，否则会惩罚“比字幕切得细”。
- 日文比对前片假名折成平假名、去标点、统一全角数字与 センチ/cm——Whisper 对同一个词写法随机。
- 官方字幕是**编辑过的精简版**，不写「ちょっと」「うん」等语气词；0.70–0.85 档大量属于这种情况，不算错。
- 参考译文与我们的译文是两份独立翻译，中文相似度低只是线索；真正的翻译错多表现为凭空出现的主语/指代。
- 画面无字幕 ≠ 幻听，多数是官方没给字幕的真实台词。

## output_test 基线（v3.0.0，Sakura-14B 单引擎；v3.1.0 的 ASR 分数与此一致）

87 句字幕覆盖 111/128 段；ASR 相似度中位数 **0.91**，平均 0.84。

| 吻合度 | 句数 | 占比 |
|---|---:|---:|
| 几乎逐字一致 | 35 | 40% |
| 很接近（只差语气词） | 18 | 21% |
| 大意对但有出入 | 20 | 23% |
| 部分错 | 10 | 11% |
| 基本错 | 4 | 5% |

人工归因造成“不知所云”的句子：**ASR 实词听错约 15 句**（数字、人名「瀬戸→セット」、「大きい→キー」等，
译文忠实地翻了错的日文）；**切分过碎约 4 句**（20/87 句被切成多段、段长中位数 1.6 s，
半截名词短语被翻成完整句）；**纯翻译错约 3 句**（缺上下文导致的指代错误）。ASR : 翻译 ≈ 3 : 1。

注意：原片烧录字幕自身也有错位（372 s 中日两行内容不对应），个别行需人工复核。
