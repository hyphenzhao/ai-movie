### 1.2 转换后内容漂移判定 V7（已合并，`cf1c801`）

问题：v3.3 的守卫只看音高/有声帧；verify_dub 的 417 条配对样本里 299 条克隆句有 43 条内容变了（说成别的字、串成外语），守卫看不见。
- `vc_guard.judge_content`：用 Whisper 复读内置句与转换句，`fold_zh`（OpenCC 繁→简、NFKC、片假→平假、去非字词）后取最大相似度。
  规则顺序：v1 复读无 CJK → 不判；`script_flip`（自动语种复读无 CJK 且强制中文复读 < `VC_DRIFT_MIN_SIM` 0.5）任意长度；`kana_leak`（≥2 假名）任意长度；
  `drift_<score>` 只在目标 ≥3 字且基线（v1 复读相似度）≥0.6 时判。解码方式**镜像 verify_dub**（自动语种，非中文再强制中文重解），校准才能迁移。
- 单元 = 转换单元：单句与整块（`chunk_out` 对 `chunk_src`）都判；音高原因优先，其次本句漂移，再次整块；块整体同进退。
  `WhisperClips`：一个进程一次加载，内容摘要缓存（`try{k}` 副本与 A/B 变体命中），mel batch 默认 1（gfx1151 上新的 conv 形状会触发 MIOpen 编译）。
- 校准（CPU 回放 417 行）：判定 292/299，拒 28（16 换语种 + 12 漂移），全部落在已知坏句内、**0** 误杀、内置句 0 误判；剩余地板 15/299 = 5.0%
  （7 条 v1 本身非中文、4 条短句、3 条呻吟基线、1 条其实正确）。所以原设计 "≤4%" 不可达；预登记改为：
  Phase 2 后按 verify 全样本坏句占比：基线 43/417 = 10.3%，**≤6.0% 采纳**、>8% 拒绝；仅克隆句 14.4% → 期望 ≤8%。
  守卫：短片克隆占比 ≥75%、`drift.error` 不出现、`reused_lipsync` 真且 `max_drift_ms` 0、一致性/验收计数不变差、每 400 句块判定 ≤5 min。
- 附带：`scripts/run_vc_only.sh <name>`（只重做 v2：VC → 一致性 → qc --force → verify_v2 → eval；不碰任何指纹阶段）；`scripts/concat_long.py`
  （原 run_long.sh 第 3 步 heredoc，长片 VC-only 重做后可直接拼接）；`03_tts_report.csv` 增列（guard/skip/chunk/pin/len/f0/漂移分/两边听到的字）。
